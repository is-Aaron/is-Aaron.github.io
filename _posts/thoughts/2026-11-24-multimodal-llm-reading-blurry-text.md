> **核心观点**：多模态大模型能认出字号很小、像素模糊的截图文字，不是因为它们有“超越物理极限的视力”，而是两件事叠加：**高分辨率视觉输入**尽量把局部细节保下来，**语言模型的语义推理**再把看不清的部分补全；而训练时大量的“读图识字”数据，让这套组合真正好用。它看清的往往不只是像素，更是像素背后的**合理性**。

---

## 一、一个常见的错觉

给大模型一张文字小到肉眼都费劲的截图，它常常能一字不差地读出来，很容易让人觉得“这模型的眼睛比人好”。

实际情况没这么神奇。模型读的不是“清晰的图”，而是**信息够用的图**。这里面有两层分工：

```
┌──────────────────────────────────────────────────────────┐
│                      截图（小字 + 模糊）                  │
└──────────────────────────────┬───────────────────────────┘
                               │
                 ┌─────────────▼─────────────┐
                 │  视觉输入层                │
                 │  动态分辨率 / 切片 / ViT   │  ← 尽量不丢细节
                 └─────────────┬─────────────┘
                               │ 视觉 token
                 ┌─────────────▼─────────────┐
                 │  融合与推理层              │
                 │  语言先验 + 版面上下文     │  ← 补全看不清的部分
                 └─────────────┬─────────────┘
                               │
                       ┌───────▼───────┐
                       │  输出文字      │
                       └───────────────┘
```

第一层决定“有多少信息进得来”，第二层决定“缺的那部分怎么补”。此外还有一个贯穿两层的前提：模型在训练时专门学过读图识字（见第四节）。

## 二、视觉输入层：先把小字保住

### 1. 动态分辨率与图像切片

早期视觉模型常把整张图缩放到固定的低分辨率（比如 `224×224`，LLaVA-1.5 也只有 `336×336`）。一张 1920×1080 的截图被压成这么小，小字的笔画早就糊成一团了，后面再聪明也没用。

现代多模态模型基本都绕开了这个限制，思路大致有两类：

| 思路 | 做法 | 代表 |
|------|------|------|
| **切片（Tiling）** | 按长宽比把大图切成多个局部图块，各自编码；同时保留一张全局缩略图 | LLaVA-NeXT 的 AnyRes（在 336 的基础分辨率上，按 2×2、1×{2,3,4}、{2,3,4}×1 等网格切分）、InternVL 1.5 的动态高分辨率（按长宽比切成 1 到 40 个 448×448 的图块，最高支持 4K 输入） |
| **原生动态分辨率** | 不强行缩放，图多大就切出多少个 patch，视觉 token 数量随分辨率变化 | Qwen2-VL 的 Naive Dynamic Resolution |

```
切片思路：

  ┌───────────────────────┐          ┌─────┐ ┌─────┐ ┌─────┐
  │                       │          │ 图块1│ │ 图块2│ │ 图块3│
  │   一张高分辨率截图     │  ──────► ├─────┤ ├─────┤ ├─────┤
  │   （小字密集）         │          │ 图块4│ │ 图块5│ │ 图块6│
  │                       │          └─────┘ └─────┘ └─────┘
  └───────────────────────┘          + 一张全局缩略图（保留整体布局）

  每个图块都以较高分辨率进入视觉编码器，小字在局部仍有足够像素。
```

局部看细节，全局看布局，两边合起来给语言模型。这是小字能被读出来的**物理前提**：像素信息没被提前丢掉。LLaVA-NeXT 的博客也提到，提高分辨率能减少模型在低分辨率图像上“凭空臆想画面内容”的幻觉。

代价也很直接：分辨率越高，视觉 token 越多，推理越慢、越贵。所以很多产品会给图片设上限，超过就会被缩小。

### 2. 屏幕字体渲染留下的灰度线索

屏幕截图里的文字不是“黑白二值”的。操作系统渲染字体时会做抗锯齿，有时还有亚像素渲染，所以即使字号很小，笔画边缘仍有细腻的灰度过渡和明暗对比。

视觉编码器（通常是 ViT 架构）提取的是高维特征向量，不是人眼意义上的“清不清楚”。人眼觉得糊成一片的区域，里面的灰度梯度可能依然包含可区分的信息。

## 三、融合与推理层：“看图”加“补全”

### 3. 语言先验：像做完形填空

这是模型面对极糊文字时最关键的优势。

传统 OCR 主要依赖局部字形匹配，笔画一粘连或残缺就容易出错。大模型不一样，它本质上是一个强大的语言概率模型。当某个字因为像素太低而轮廓不清时，它会结合：

- 前后句子的语境
- 常见的词组搭配
- 所处领域的背景知识

做概率推断，这和人在读潦草字迹时“连蒙带猜”是同一种机制。语境越强、词越常见，还原得越准。

举个例子：

```
看到的：   "请在 3 个工作日内完 ▒ 审 ▒"
                                  ↑      ↑
                              笔画残缺   笔画残缺

候选：  完成 / 完善 / 完毕     审批 / 审核 / 审查
上下文：“工作日内” + “审”      → “完成审批 / 完成审核”概率最高
```

单看那个残缺的字，人和模型都认不出来；放回句子里，答案就缩小到很少几个候选。

### 4. 原生多模态注意力与版面语境

在主流的视觉语言模型里，图像经视觉编码器得到的视觉 token 会和文本 token 一起进入语言模型，在同一套自注意力里交互（原生多模态模型更是从训练起就联合建模）。模型看的不只是“这个字长什么样”，还有：

- 整张截图的**版面结构**：是聊天窗口、表格、网页、还是代码框
- **控件位置和图标**：右上角的小字更可能是“关闭”“设置”，而不是随机文字
- **主题与上下文**：整页都在讲数据库，那么 `idx` 更可能是 index，不是别的

这些信息进一步压缩了候选字符和词汇的范围。

## 四、训练：模型被专门教过“读图识字”

前面两层讲的是结构，但结构只是必要条件。现代视觉语言模型的训练数据里，通常专门包含文档、图表、截图等 OCR 类任务：

- LLaVA-NeXT 在数据配方里加入了 DocVQA、SynDog-EN（文档类）以及 ChartQA、DVQA、AI2D（图表类），明确用来保持并提升 OCR 能力。
- InternVL 1.5 构建了覆盖常见场景和文档图像的中英双语数据集，论文称其显著提升了 OCR 相关任务的表现。
- Qwen-VL 的标题里就写着“Text Reading”，把文字读取作为核心能力来训练。

所以它认小字、认模糊字的能力，一部分来自结构设计，一部分来自训练时见过足够多的“图 + 对应文字”配对。

## 五、能力边界：什么时候会认错

既然模型靠的是“视觉线索 + 语言先验”的联合推断，准确率就会随场景明显波动：

| 场景 | 准确率 | 原因 |
|------|--------|------|
| 常规自然语言句子、常见词汇 | 高 | 语言先验强，容错空间大 |
| 有明显上下文逻辑的段落 | 高 | 前后文能互相印证 |
| 版面结构清晰的界面截图 | 高 | 版面语境缩小了候选范围 |
| **随机字符串**（密码、验证码、哈希、序列号） | **低** | 没有规律可补，只能靠像素本身 |
| 生僻专有名词、人名、地名 | 低 | 语言模型也没见过，猜不准 |
| 严重压缩且毫无上下文的孤立字符 | 低 | 两层信息都缺 |

要特别警惕一个现象：**模型不会因为没看清而沉默，它会给出一个“看起来合理”的答案**。对语言先验强的场景，这是优点；对 `0` 和 `O`、`1` 和 `l`、`8` 和 `B` 这类必须逐字精确的内容，这就是幻觉的来源。

## 六、实际使用时的几条建议

1. **能放大就放大**：截图前先放大界面，或者只截取需要的区域。裁剪比整屏截图可靠得多。
2. **别把压缩当省事**：反复转发、微信压缩后的截图，信息已经损失，模型也补不回来。
3. **需要精确的内容要二次核对**：账号、密钥、命令行参数、金额、序列号，不要完全信模型的“读出来”，对照原文或复制文本。
4. **给模型一点上下文**：告诉它这是什么类型的截图、大概在讲什么，等于主动加强了语言先验。
5. **关键场景用专门的 OCR 兜底**：需要可审计、可复现的文本提取时，传统 OCR 加人工校验仍然更稳。

## 七、一句话总结

大模型能认出“几乎没像素”的截图文字，靠的是**切分与保留局部特征**打底，再靠**海量语言规律与上下文推理**做补全，而针对读图识字的专门训练让这套机制稳定可用。

所以它的“视力”并没有超越物理极限，它是在像素给出的有限证据上，选了一个最合理的解释。证据足够时，这个解释几乎总是对的；证据不足而又没有规律可循时，它仍然会给出一个自信但可能错误的答案。

## 术语表

| 术语 | 解释 |
|------|------|
| **多模态大模型（MLLM / VLM）** | 能同时处理文本、图像等多种输入的大模型，常见形态是“视觉编码器 + 语言模型” |
| **OCR** | Optical Character Recognition，光学字符识别，把图像里的文字提取成文本 |
| **ViT** | Vision Transformer，把图像切成 patch 序列后用 Transformer 编码的视觉模型 |
| **Patch** | 图像被切成的小方块，是 ViT 处理的基本单位 |
| **视觉 token** | 图像经视觉编码器后得到、送入语言模型的向量序列，数量随分辨率增长 |
| **Tiling / 切片** | 把高分辨率图像切成多个局部图块分别编码的策略 |
| **AnyRes** | LLaVA-NeXT 采用的任意分辨率方案，按长宽比选择切片网格并保留全局缩略图 |
| **Naive Dynamic Resolution** | Qwen2-VL 的原生动态分辨率方案，视觉 token 数量随图像大小变化 |
| **抗锯齿 / 亚像素渲染** | 操作系统渲染屏幕字体时的平滑技术，使小字边缘带有灰度过渡 |
| **语言先验（Language Prior）** | 模型从大量文本中学到的语言规律，用来在信息不全时推断最可能的内容 |
| **幻觉（Hallucination）** | 模型给出看似合理但与事实或输入不符的输出 |
